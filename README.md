# AI CareerPilot 🚀

An AI-powered Resume Analyzer and Job Matcher built with Python and Streamlit.

## Features
- Upload a resume in PDF format
- Extract resume text
- Detect skills using keyword matching
- Compare a resume with a job description
- Calculate TF-IDF text similarity
- Visualize matching and missing skills
- Generate a basic 30-day learning plan

## Tech Stack
- Python
- Streamlit
- PyMuPDF
- Scikit-learn
- Plotly

## Run Locally

1. Clone or download this repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `streamlit run app.py`

## Limitations
The similarity score is a text-similarity measure, not an official ATS score or a prediction of hiring success. Skill detection uses a predefined keyword list.

## Privacy
Use sample resumes for public demonstrations. Avoid uploading sensitive personal information.
